# Verification report

The test suite runs with `npm test` and covers BM25 ranking, policy rules and explicit ODRL prohibitions, ALA CLI simulation and saved run history, MCP tools, password-free startup, externally supplied audit identity, HF search/preview/download, Zenodo files, DCAT catalog/download, editable multi-source settings with secret redaction, EDC catalog/approval/negotiation/EDR/transfer with a simulated connector, local cache TTL, publication form validation, Hugging Face adapter calls, Zenodo upload/draft/publish through a mock service, and audit hash-chain integrity. Source and UI JavaScript syntax is checked with `node --check`; whitespace changes are checked with `git diff --check`.

The server was started locally with `npm start` without a password. Chromium rendered the English Settings page and populated its source list through JavaScript. The new Publish and Monitoring layouts were rendered at desktop and mobile widths. The Docker image built successfully with `npm ci --omit=dev`. The public Hugging Face dataset search endpoint returned HTTP 200 and dataset results from this machine. The current code has no built-in authentication. Browser and API access must be protected by the organization's external proxy in a deployment.

The EDC adapter has not been validated against an actual provider because this repository has no organization-specific consumer connector, provider DSP address, participant ID, or credentials. Real Hugging Face and Zenodo publication was not attempted without account tokens. ALA was discovered locally, but its Bubblewrap sandbox could not start in this managed environment (`EPERM`); BM25 analysis remains functional and ALA is disabled by default. External source availability and account permissions must be checked in the target environment.
