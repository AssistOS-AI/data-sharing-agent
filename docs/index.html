Achilles IDE Datasharing Hub

Specification, setup, and API documentation

Start here

Run npm start, then open the local interface. No Hub password is required. In deployment, put the Hub behind your organization's authentication proxy.

Data sources

Public Hugging Face and Zenodo search work without an account when upstream services are reachable. Add account tokens, EDC connectors, or JSON-LD DCAT catalogs from Settings. EDC requires an existing consumer connector and a provider DSP endpoint.
