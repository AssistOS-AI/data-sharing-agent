Source configuration


Hugging Face account
For publication, create a token with write access to the target dataset repository in Hugging Face account settings and grant the account access to any gated dataset. Token documentation.


Zenodo account
Zenodo is a research repository. Public search needs no token. Publication needs a deposit token with write and actions scopes.
Create an access token in Zenodo account settings; enable deposit:write and deposit:actions. See the deposit API guide.


EDC / European data space connectors
Add as many connectors as needed. Each connector has its own source ID and provider. EDC negotiates access over Dataspace Protocol. You need a running consumer connector and the provider endpoint. Eclipse EDC · Setup guide.
Add or edit a connector
Requires a consumer EDC Management API and a provider DSP endpoint. Credentials depend on that data space.

DCAT catalogs
DCAT is a standard format for describing datasets and their download links. A catalog usually provides metadata, not an account or publishing destination. Add multiple JSON-LD catalogs with unique source IDs. What is DCAT? · European DCAT-AP.
